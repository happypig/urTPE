The stop rule — cycle.classify_exit() (cycle.py L201) — and the contract it serves. A non-zero exit is a refusal, not a flake: a later scheduled run never retries a refused hash.

classify_exit(step, exit_code, timed_out)

  • publish_report: ok only if exit 0 and no timeout — else publish_failed
  • timed_out → refusal
  • exit 0 → ok
  • exit 5 → transient (a held lock: the moment, not the data)
  • anything else → refusal

dirty_decision(candidate_ready, dirty_paths)

  • refuse only when a gazette is ready AND an owned tracked path has uncommitted changes → exit 6
  • a quiet day is never stopped by a dirty tree: it writes nothing
  • only checked when the cycle starts fresh at ingest; past it, the dirt is this cycle’s own

The four decisions worth reading (cycle.py docstring)

1 · The archive decides

  • poll_gazette reports new_gazette once; later polls say unchanged
  • so the ingest target is chosen from the archive (pick_candidate), never from a status word

2 · Refusal waits, a busy moment does not

  • non-zero exit = refusal → stopped, awaiting a person
  • held lock / dirty tree / other cycle = transient → resume next run

3 · Report published last (D13)

  • mark_finished BEFORE publish_report
  • a failed push is publish_failed and never un-finishes the ingest

4 · Progress kept after every step

  • the ingest moves the dataset — without a progress entry the next run sees “nothing to do”
  • mark_in_progress(next_stage) after each ok step enables resume

The split that makes both files testable: pure rules vs side effects. Tests replace Deps; main() builds the real ones.

scripts/run_cycle.py — adapters (everything that touches the world)

  • _real_runner() — subprocess with per-step timeout (timeout = exit 124 + timed_out)
  • _real_git_dirty() — the ONLY git command: read-only status --porcelain --untracked-files=no
  • _dataset_date() — reads published_date from the payload head (first 8 KiB)
  • CycleStore — cycle_log.jsonl append + atomic cycle_state.json write (tmp + os.replace)
  • SingleWriterLock / LockHeld — archive lock for the cycle, probe-only lock for data/
  • _poll_status() — poll stdout JSON → (status, ok)
  • run() · _cycle() · _dry_run() · _finish() — the orchestration on the flow tab
  • main() — builds Deps; status page is optional (import cycle_status)
