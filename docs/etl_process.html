3Extract — refuse rather than approximate擷取 — 寧可拒絕，不求近似

pymupdf reads each page with find_tables(strategy="lines"); cell boundaries come from the document's own ruling lines, never stored coordinates. Seven columns verbatim: 編號, 核定日期, 行政區, 案名, 地號, 實施者, 更新規劃單位 — plus gazette_id. A structure the reader cannot read exactly raises TableStructureError (exit 3); nothing is written.pymupdf 以 find_tables(strategy="lines") 讀每一頁； 儲存格邊界來自文件自身的格線，絕不用儲存的座標。 七個欄位逐字保留：編號、核定日期、行政區、案名、地號、實施者、更新規劃單位 — 再加 gazette_id。讀取器無法精確解讀的結構會拋出 TableStructureError（exit 3）；不寫出任何東西。

3.1 The two-fault distinction on a 地號 cell3.1 地號儲存格的雙重故障區分

Reader fault — page furniture讀取器故障 — 頁面物件
The city prints the page number inside the last row's 地號 cell.市政府把頁碼印在最後一列的地號儲存格裡。
✓ Stripped — only when the trailing digits equal that page (strip_page_footer).✓ 剔除 — 僅當尾端數字等於該頁頁碼 （strip_page_footer）。
Publisher fault — truncation出版方故障 — 截斷
The city cuts the cell at the printed row height and never draws the remainder; the text is absent from the PDF.市政府在列印行高處切斷儲存格，且從不繪出剩餘部分； 文字不在 PDF 裡。
✗ Excluded and named — never repaired by inference.✗ 排除並命名 — 絕不以推測修補。

A cell is publisher-truncated when it ends in a tail pattern (、，, / digit / sub-parcel hyphen) or lost its closing phrase while showing fewer parcels than its 案名 declares. A completed closing phrase (地號等N筆土地) is never count-checked — 48 rows per Gregorian gazette disagree with their 案名 and are complete as published.儲存格以尾部模式結尾 （、，,／數字／子地號連字號）、或顯示的地號數少於案名宣告且失去結尾語時，即為出版方截斷。 完整的結尾語（地號等N筆土地)永不做筆數檢查 — 每份西元曆公報有 48 列與其案名 不一致，但照原樣是完整的。

viewer/dashboard.html + viewer/dashboard.js load projects.data.js with the ?v= that index.html names and compute every figure in the browser at render time — stalled cases, review workload and speed, relocation demand, public land — so nothing on the page is typed by hand (policy-dashboard spec). The district, the language and the review view live in the URL hash. The review chart has two views, switched in its own card: 中位數 (default) draws the median of both intervals by year of first approval; 完整 (#review=full) draws the spread behind them — the pre-permit interval as a fan (shortest-to-longest band, 25th-to-75th-percentile band, median line, straight segments) and the first-approval interval as one box per year (thin line, box, dot), with one tooltip per year listing the five values and the project count of both intervals. A percentile is read by linear interpolation between the two nearest ranks, to one decimal. Unlike the viewer's smoke script, this render path is in pytest: tests/test_dashboard_rules.py renders the real page through node scripts/dashboard_smoke.js.viewer/dashboard.html + viewer/dashboard.js 以 index.html 所指定的 ?v= 載入 projects.data.js， 在瀏覽器中於渲染時算出每一個數字 — 停滯案件、審議量能與時程、安置需求、公有地 — 頁面上沒有任何手寫的數字（policy-dashboard spec）。 行政區、語言與審議圖表的檢視都存在 URL hash 裡。審議圖表有兩種檢視，在圖表自己的卡片上切換： 中位數（預設）畫出兩段期間依首次核定年度的中位數；完整（#review=full）畫出中位數背後的分布 — 自申請至建照核發前之核定為連續的扇形（最短至最長的淺色帶、第 25 至第 75 百分位的深色帶、中位數線，一律直線段）， 自申請至首次核定為每年一個箱形（細線、方塊、圓點），每個年度一個提示框，列出兩段期間各自的五個數值與專案數。 百分位以相鄰兩個排序位置之間的線性內插計算，取到小數一位。與檢視器的 smoke script 不同， 這條渲染路徑在 pytest 內：tests/test_dashboard_rules.py 透過 node scripts/dashboard_smoke.js 渲染真實頁面。

9Operating the pipeline操作管線

Full ingest of a new gazette:完整匯入一份新公報：

1.Run python scripts/poll_gazette.py — it archives on new_gazette.執行 python scripts/poll_gazette.py — 遇 new_gazette 時封存。
2.Ingest: python -m urtpe.cli "D:\project\urtpe-gazettes\核定案件-YYYY-MM-DD.pdf" -o data --viewer viewer --links匯入：python -m urtpe.cli "D:\project\urtpe-gazettes\核定案件-YYYY-MM-DD.pdf" -o data --viewer viewer --links
3.Read the run output — tripwire PASS, reconcile, ledger, exclusion count. Any [CENSUS]/[EMISSION] line names a real defect.讀執行輸出 — 絆線 PASS、對帳、帳本、排除數。 任何 [CENSUS]/[EMISSION] 列都指出真實缺陷。
4.Exit 0 commits the dataset (mind the ~24 MB diff). Exit 2/3/4/5 is a refusal — diagnose, never bypass with a flag.exit 0 收入資料集（注意約 24 MB 的差異）。exit 2/3/4/5 是拒絕 — 先診斷，絕不用旗標繞過。
5.Push main so Pages serves the new payload; verify with python scripts/check_deploy.py.推送 main 讓 Pages 供應新 payload；以 python scripts/check_deploy.py 驗證。
Rules that outlast any single run比任何單次執行都長久的規則
One run per output tree (the lock is stale after 6 h or a dead PID — check the PID before deleting it) · never key anything durable on 編號 · manual corrections go in the ledger, not a dated script · data/.link_cache/ is durable state — five backup dirs from past incidents exist because it was once lost · tests: python -m pytest (1,231 collected; one deliberate skip at tests/test_idempotent_flags.py:117).每個輸出樹一次執行（鎖在 6 小時後或 PID 已死即過期 — 刪除前先確認 PID）· 絕不以 編號 作為任何持久鍵 · 人工更正進帳本，不寫日期版的一次性腳本 · data/.link_cache/ 是持久狀態 — 過去事故留下的五個備份目錄就是因為它曾經被清掉 · 測試：python -m pytest（蒐集 1,231 項；一項刻意 skip 於 tests/test_idempotent_flags.py:117）。
